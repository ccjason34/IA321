Depreciation Allocates Cost, Not Value
Depreciation is the accounting process of allocating the cost of a long-lived asset to expense over the periods that benefit from using the asset.
Core idea: depreciation is not a cash payment and not an attempt to show current market value. It allocates the asset's depreciable base over useful life. Student trap: residual value matters differently depending on the method.
Straight-Line
Same depreciation expense each year. Best when the asset provides benefits evenly over time.
(Cost - Residual) / Life
Double-Declining-Balance
Higher expense early, lower expense later. Residual value is not subtracted in the annual formula, but book value cannot fall below residual value.
Beginning BV x (2 / Life)
Sum-of-the-Years'-Digits
Accelerated depreciation using a shrinking fraction. The numerator counts remaining life; the denominator is the sum of all years.
Base x Remaining years / SYD
Units-of-Production
Expense follows actual use. More miles, units, or hours means more depreciation.
Rate per unit x Actual units

🎯 The conceptual punchline
All four methods total $45,000 over 5 years (= $50,000 cost − $5,000 residual). Every method ends at $5,000 book value.
SL: $9K + $9K + $9K + $9K + $9K = $45,000
DDB: $20K + $12K + $7.2K + $4.32K + $1.48K = $45,000
SYD: $15K + $12K + $9K + $6K + $3K = $45,000
UOP*: $10.8K + $9K + $8.1K + $9.9K + $7.2K = $45,000 (* assumed future miles)
The depreciable base never changes. Only the timing of expense changes.
Interpretation: straight-line is even, double-declining and SYD are accelerated, and units-of-production follows actual use.

Why Debit or Credit?
Expense rule
Expenses move like assets. Expenses increase with debits.
Contra-asset rule
Accumulated depreciation is a contra-asset. It increases with credits.
Cash check
No cash is paid when depreciation is recorded.
Balance check
The debit amount equals the credit amount.
