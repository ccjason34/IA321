Disposition: Gain or Loss

When a plant asset is sold, first update depreciation. Then compare cash proceeds with book value to decide whether the company has a gain or a loss.

The Setup: what must happen before recording the sale?
A plant asset disposal removes the asset and its accumulated depreciation from the books. But before removal, depreciation must be recorded up to the date of sale.
Disposition memory hook: update depreciation first, compute book value second, compare cash proceeds third, then record the disposal entry.

Step 1
Update depreciation
Record depreciation from the last entry date through the sale date.
Step 2
Find book value
Cost minus updated accumulated depreciation.
Step 3
Cash - book value
Positive is gain. Negative is loss.
Why update depreciation FIRST?skipping the update gives the wrong answer
❌ WITHOUT update (wrong)
Book value = $18,000 − $10,800 = $7,200
$7,000 cash − $7,200 BV = ($200) loss
Reports a loss — but that's not the real economics.
✓ WITH update (right)
Book value = $18,000 − $11,400 = $6,600
$7,000 cash − $6,600 BV = $400 gain
The half-year of dep ($600) belongs in the period it was earned, not lumped into the disposal. Recording it first restores the correct book value.
Skipping the update flips the sign of the answer by $600. Always update first.

Once book value is known, the gain or loss rule is simple: cash proceeds minus book value.
Memory hook: Cash received above book value is a gain. Cash received below book value is a loss. Cash equal to book value means no gain or loss.
